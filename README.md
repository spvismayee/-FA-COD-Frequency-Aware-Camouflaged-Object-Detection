# FA-COD: Frequency-Aware Camouflaged Object Detection

Frequency-Aware Camouflaged Object Detection using a **Res2Net-50 encoder**, multi-scale feature fusion, and FFT-based frequency enhancement.

## Overview

FA-COD is a deep learning approach for **Camouflaged Object Detection (COD)**. The goal is to identify objects that blend into their surroundings and are therefore difficult to distinguish from the background.

The model combines spatial and frequency-domain information to improve feature representation and produce more accurate segmentation masks.

## Model Architecture

The main components of FA-COD are:

- **Res2Net-50 Encoder:** Extracts hierarchical features at multiple scales.
- **FFT-based Frequency Enhancement:** Enhances feature representations at all four encoder levels using frequency-domain information.
- **Feature Pyramid Network (FPN):** Combines multi-scale features to capture both detailed and high-level information.
- **Residual Decoder:** Progressively reconstructs the segmentation mask using refined feature maps.
- **Boundary Refinement Module:** Uses Sobel-based edge information to improve object boundary details.
- **Auxiliary Supervision:** Provides additional supervision during training to support feature learning at multiple levels.

## Dataset

The model was trained and evaluated using the **CAMO dataset**.

For this experiment, 1,000 images from the CAMO `Train` folder were divided into:

| Subset | Split |
|---|---:|
| Training | 70% |
| Validation | 15% |
| Testing | 15% |

The split was generated using a fixed random seed of 42.

**Note:** The evaluation subset was created from the CAMO training folder. It is not the official CAMO test set.

## Training Configuration

| Setting | Value |
|---|---|
| Input image size | 384 × 384 |
| Batch size | 4 |
| Gradient accumulation | 4 steps |
| Effective batch size | 16 |
| Maximum epochs | 80 |
| Optimizer | AdamW |
| Learning rate scheduler | OneCycleLR |
| Early stopping patience | 25 epochs |
| Encoder | Res2Net-50 |

The training process also uses data augmentation and a weighted sampling strategy to give more attention to images containing smaller camouflaged objects.

## Evaluation Metrics

The model is evaluated using the following metrics:

| Metric | Recorded result |
|---|---:|
| S-measure | 0.9052 |
| E-measure | 0.8907 |
| F-measure | 0.7745 |
| MAE | 0.0735 |
| Dice | 0.7772 |
| IoU | 0.6773 |

These values are from the notebook's recorded evaluation on the held-out subset described above. They should not be interpreted as results on the official CAMO test set.

## How to Run

The notebook is designed to run in **Google Colab**.

1. Open `FA_COD_v8.ipynb` in Google Colab.
2. Select a GPU runtime.
3. Install the dependencies listed in `requirements.txt`.
4. Download the CAMO dataset separately and place it in the directory expected by the notebook.
5. Mount Google Drive when prompted.
6. Run the notebook cells in order.

### Requirements

The main dependencies are listed in `requirements.txt`, including PyTorch, Albumentations, timm, and segmentation-models-pytorch.

## Notes

- The CAMO dataset is not included in this repository and must be obtained separately.
- The notebook is named `FA_COD_v8`, while the model class retains the name `FACOD_v7` because the v8 update changes the training configuration rather than the model architecture.
- Results may vary depending on the dataset setup and execution environment.
